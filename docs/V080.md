# Jau 0.8

Jau 0.8 strengthens native `.jaux` interoperability, compiler diagnostics, debugging, and everyday syntax.

## Native `.jaux` COFF symbol resolution

For an installed native package such as:

```ini
name="MathX"
version="1.0.0"
main="src/main.jau"
type="native"
native_windows_x86_64="native/windows-x86_64/mathx.obj"
native_windows_x86="native/windows-x86/mathx.obj"
```

Jau now extracts target-native object files as opaque binary objects, reads their COFF defined-external symbol table before AOT emission, and feeds the discovered native symbols to the AOT resolver. The Jau source wrapper remains source-only:

```jau
extern func mx_add(a:int,b:int):int;

namespace MathX {
    func add(a:int,b:int):int {
        return mx_add(a,b);
    }
}
```

The AOT resolver can match common COFF decoration forms such as `mx_add`, `_mx_add`, and stdcall-style suffixes. `jauld` also performs canonical decorated-symbol matching as a linker fallback. Ambiguous matches are rejected instead of guessed.

Use `extern "C"` for C++ extension ABI exports whenever possible.

## Compiler diagnostics and debugging

Validate source without keeping a build artifact:

```text
jauc check main.jau
jauc check main.jau --target windows-x86_64 --debug
```

Run the VM with instruction tracing:

```text
jauc debug main.jau
```

Enable native/package diagnostics:

```text
jauc asm main.jau -o main.s --target windows-x86_64 --debug
jauc native main.jau -o main.exe --target windows-x86_64 --debug
```

Native debug output reports resolved package objects and discovered COFF symbols, for example:

```text
[jauc:resolve] target=windows-x86_64 package_objects=1 native_symbols=3
[jauc:object] ...mathx.obj
[jauc:symbol] mx_add
[jauc:symbol] mx_mul
[jauc:symbol] mx_pow
```

`jauc` catches top-level compiler exceptions and reports a normal diagnostic rather than allowing an uncaught exception to terminate the process. Native failures are separated into AOT, assembler, symbol-discovery, and linker stages.

## Syntax additions

Jau 0.8 adds:

- C-style `for` loops with correct `continue` routing through the step expression.
- `++` and `--` variable updates.
- `+=`, `-=`, `*=`, `/=`, `%=` compound assignments.
- `fn` as an alias for `func`.
- `var` as an alias for `let`.
- `/* ... */` block comments in addition to existing line comments.

Example:

```jau
/* modern Jau syntax */
fn sum_to(n:int):int {
    var total:int = 0;

    for (var i:int = 0; i < n; i++) {
        if (i == 3) {
            continue;
        }
        total += i;
    }

    return total;
}

print(sum_to(6));
```

Type annotations accepted in function parameters, return positions, and variable declarations remain syntax metadata in 0.8; this release does not claim a complete static type checker.
