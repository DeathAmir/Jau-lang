# Jau 0.8.1

Jau 0.8.1 fixes native calls declared inside namespace facades and expands integer-oriented syntax.

## Native package binding

`extern func` declarations keep their C ABI symbol name even when written inside a Jau namespace. The AOT backend also accepts a call when a matching symbol was discovered directly from a package COFF object. Namespace-local Jau calls resolve relative to the current namespace in both VM and AOT modes.

## Syntax additions

- `function` and `def` aliases for `func`
- `nil` alias for `null`
- `and`, `or`, `not` keyword operators
- bitwise `&`, `|`, `^`, `~`
- shifts `<<`, `>>`
- hexadecimal `0x`, binary `0b`, octal `0o` integer literals
- numeric separators such as `1_000_000`

Existing Jau 0.8 syntax such as `for`, `++`, `--`, compound assignments, `fn`, `var`, and block comments remains supported.
