# Jau 0.8.2 native extension regression

This marker keeps the `.jaux` C/C++ regression tied to the 0.8.2 stability release.

The test must continue to prove that package source is parsed as Jau while target `.obj` data remains binary, that C ABI symbols are discovered before AOT, and that the installed package links and executes on Windows x86 and x64.
